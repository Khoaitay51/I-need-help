If you want to change the color or formatting of the text, select the text, and then on the Home tab, in the Font group, click the Dialog Box Launcher. Click the shape (but not the text inside of the shape), and then on the Insert tab, in the Links group, click Hyperlink. In the Address box, type the Web address, and then click OK. To test the hyperlink, in Slide Show view, click the rectangle that contains the hyperlink. Top of Page.
