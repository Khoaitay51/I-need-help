Human reproduction takes place as internal fertilisation by sexual intercourse. During this process, the male inserts his penis, which needs to be erect, into the female's vagina, and then either partner initiates rhythmic pelvic thrusts until the male ejaculates semen, which contains sperm, into the vaginal canal. While normal cells contains 46 chromosomes, 23 pairs, gamete cells only contain 23 chromosomes, and it is when these two cells merge into one zygote cell that genetic recombination occurs and the new zygote contains 23 chromosomes from each parent, giving them 23 pairs.
