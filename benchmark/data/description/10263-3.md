The male reproductive system contains two main divisions: the testes where sperm are produced, and the penis. In humans, both of these organs are outside the abdominal cavity. While normal cells contains 46 chromosomes, 23 pairs, gamete cells only contain 23 chromosomes, and it is when these two cells merge into one zygote cell that genetic recombination occurs and the new zygote contains 23 chromosomes from each parent, giving them 23 pairs.
