BatchGeo uses the Google Maps Geocoding API, known to have some of the highest quality data available. Other services require you to write code or manually geocode addresses one by one, but our service performs everything you need to do in a few easy steps. 1 Generally you would pick around 50 feet from the address block. 2  There is no way to know for sure how far back the building or building entrance is located, but 50 feet is usually close. 3  Finally, the geocoder has to choose a side of the street to place the address.
