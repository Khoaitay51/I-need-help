The Globe was built in 1599 using timber from an earlier theatre, The Theatre, which had been built by Richard Burbage's father, James Burbage, in Shoreditch in 1576. The Burbages originally had a 21-year lease of the site on which The Theatre was built but owned the building outright. A modern reconstruction of the Globe, named  Shakespeare's Globe , opened in 1997 approximately 750 feet (230 m) from the site of the original theatre.
