PEAP does not specify an authentication method, but provides additional security for other EAP authentication protocols, such as EAP-Microsoft Challenge Handshake Protocol version 2 (MS-CHAP v2), that can operate through the TLS-encrypted channel provided by PEAP. 1 Support for the fragmentation and reassembly of messages, allowing the use of EAP types that do not provide this functionality. 2  Clients with the ability to authenticate an NPS server or other RADIUS server. 3  Because the server also authenticates the client, mutual authentication occurs.
