Issue: Excel automatically makes column widths too wide. I often work with pivot tables that have URLs as rows of data, and the URLs can be quite long. In the past, whenever I changed the data and refreshed the pivot table, Excel would automatically resize the column width, making the column as wide as the longest URL. 1 In the Pivot Table Options dialogue box, click the Layout and Format tab, and then uncheck the box Autofit column widths on update.
