When you adjust the width of a column, Excel, by default, readjusts the column width to fit the longest string of data. To keep column widths fixed, you'll need to adjust the format settings. Instructions. Launch the Microsoft Excel program and open a spreadsheet in which a pivot table is already created. Right-click the pivot table and choose Table Options from the resulting menu. Uncheck the Auto Format Table box and click OK.. Adjust the column widths and refresh the pivot table. The columns will stay fixed at the width you specified instead of reformatting to fit the data
