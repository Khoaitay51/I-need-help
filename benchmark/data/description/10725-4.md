If you don’t have a wi-fi router and would like to share your internet connection (Wifi, LAN, Cable Modem, Dial-up, Cellular, etc.) from Windows 8 computer with wi-fi only devices like Surface tablet, you could use command prompt to create Wireless ad-hoc connections. Windows 8 pro OS is missing Start Orb and includes some hidden items, like the ability to turn your device into a personal WiFi hotspot. Creating a hotspot is easy in windows 7 with ad hoc network support, but it is complicated to do with Windows 8.
