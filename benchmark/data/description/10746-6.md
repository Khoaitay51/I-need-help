In my opinion, a method is a more general concept than algorithm and can be more or less anything, e.g. writing data to a file. Just about anything that should happen due to an event or to some logical expression. In computer science an algorithm still is a step-by-step manner towards solving a problem-an implementation-agnostic set of steps. A method commonly refers to a chunk of code associated with a class or object that does some task-it can implement many algorithms potentially. share | improve this answer.
