In the context you state (Newton's method, etc.) there is no essential difference between an algorithm and a method. Both are sets step-by-step instructions for solving a problem. In computer science an algorithm still is a step-by-step manner towards solving a problem-an implementation-agnostic set of steps. A method commonly refers to a chunk of code associated with a class or object that does some task-it can implement many algorithms potentially. share | improve this answer.
