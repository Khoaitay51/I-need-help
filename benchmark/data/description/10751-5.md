PICO (alternately known as PICOT) is a mnemonic used to describe the four elements of a good clinical question. It stands for: P--Patient/ProblemI--InterventionC--ComparisonO--Outcome. Many people find that it helps them clarify their question, which in turn makes it easier to find an answer. More on PICO & Clinical questions. We can use our PICO statement to list terms to search on. Under each letter, we'll list all the possible terms we might use in our search.
