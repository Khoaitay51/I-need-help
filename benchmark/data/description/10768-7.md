Memoir (from French: memoire : mémoire, memoria meaning memory or), reminiscence is a literary nonfiction. Genre more, specifically it is a collection of memories that an individual writes about moments or, events both public or private that took place in the'subject s. life This kind of memoir refers to the idea in ancient Greece and Rome, that memoirs were like memos, or pieces of unfinished and unpublished writing, which a writer might use as a memory aid to make a more finished document later on.
