SNMP is a network management standard widely used with TCP/IP networks and, more recently, with Internetwork Packet Exchange (IPX) networks. The SNMP standard includes the following Request for Comment (RFC)–compliant constructs: The Management Information Base II (MIB II), RFC 1213. SNMP performs its management services by using a distributed architecture of management systems and agents.
