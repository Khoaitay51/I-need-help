To use Amazon CloudFront, you: 1  For static files, store the definitive versions of your files in one or more origin servers. 2  These could be Amazon S3 buckets. 3  For your dynamically generated content that is personalized or customized, you can use Amazon EC2 – or any other web server – as the origin server. Like other AWS services, Amazon CloudFront is a self-service, pay-per-use offering, requiring no long term commitments or minimum fees. With CloudFront, your files are delivered to end-users using a global network of edge locations.
