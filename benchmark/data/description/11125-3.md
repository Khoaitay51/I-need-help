Adaptive Immunity Definition. Adaptive immunity is an important part of the immune system. It is protection from an infectious disease agent that is mediated by B-and T-lymphocytes following exposure to specific antigen, and characterized by immunological memory. A key feature of the adaptive immune system is memory, the development of immunological memory, in which each pathogen is remembered by a signature antibody. Part of activated B cells and T cells can develop to memory cells.
