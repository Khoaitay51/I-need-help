Ford 289 ‘K Code’ engine in 1968 Mustang GT350 (credit: Stephen Foskett). The code refers to the fifth character of the car’s VIN (vehicle identification number), and denotes the engine the car was fitted with when it left the factory. The most common are C and A, both of which refer to the 289 cu in (4.7-litre) V8 engine with either a two-or four-barrel carburettor
