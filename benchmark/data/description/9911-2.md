Use of set builtin command. Bash shell offers debugging options which can be turn on or off using set command. 1  set-x: Display commands and their arguments as they are executed. 2  set-v: Display shell input lines as they are read. $ ./script.sh. Output: Now set DEBUG to off (you need to edit the file): _DEBUG=off. Run script: $ ./script.sh. Output: Above is a simple but quite effective technique. You can also try to use DEBUG as an alias instead of function.
