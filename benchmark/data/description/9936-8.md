IPsec (Internet Protocol Security) is a set of protocols and standards intended to provide security for information sent over the Internet. Specifically, IPsec was created to provide the following sorts of protection for Internet traffic: 1  Encryption to ensure data confidentiality. Although IU has mostly implemented IPsec in VPN service, it is designed to be used more generally, and is built into the IPv6 standard for general use. Because of this, any modern operating system that can use the IPv6 protocol will have IPsec capabilities.
