RMS. Literally root mean square.. A DC voltage that will produce the same heating effect (power output in Watts) as the AC voltage. For a sine wave, the RMS value is equal to 0.707 times the peak value of an AC voltage. Example: divide Peak-to-Peak by 2 (or in half) and multiple by 0.707 = RMS voltage. If 75w.RMS is not the total power of the system but rather the individual outputs then that should be plenty for the HTS.
