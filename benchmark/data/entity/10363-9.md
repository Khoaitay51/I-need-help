High in Vitamin C. Fruits and vegetables that contain 12 mg or more vitamin C per reference amount (20% of the Daily Value per reference amount) qualify to carry the label “high in vitamin C.”. Fruits and vegetables that contain 6 mg to less than 12 mg vitamin C per reference amount (10-19% of the Daily Value per reference amount) qualify to carry the label “good source of vitamin C.”. Artichoke. Asparagus. Banana. Blueberries. Carrot. Celery. Cherries, Sweet. Corn.
