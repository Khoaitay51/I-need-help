Scripting languages are a subset of programming languages. 1  Scripting languages are not compiled to machine code by the user (python, perl, shell, etc.). 2  Some programming languages that are not scripting (C, C++, Haskell, and other 'compiled' languages), are compiled to machine code, and is subsequently run. On the other hand a programming language requires a compiler to be compiled. Without a compiler you have no use of a program written in C, C++ and other programming languages. You need to first compile the language before using these codes. This is the main difference between them
