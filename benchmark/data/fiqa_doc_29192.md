# Financial Advisory

**Doc ID**: 29192  
**Domain**: Finance / Investment Advice  

---

The state and local tax deductions (including property taxes) disproportionately benefit the rich ([88% of the benefit is to those with AGI &gt;$100,000](https://taxfoundation.org/state-and-local-tax-deduction-primer/)).   Cutting SALT would be a progressive reform. However, it would reduce the subsidy for state and local taxes, so there is a trade off.
