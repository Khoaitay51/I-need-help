The cost to install a gas pool heater is $500-$1500 How Much does it Cost to Run a Gas Pool Heater? Like heat pumps, the cost to heat a pool with gas will vary, by pool size and temperature rise, and also by month. In Summation-for most inground pool owners, installing a New pool heater (not a replacement, which has a cheaper installation cost), new pool heaters cost between $1500-$3500, depending on type and size. The cost to run a pool heater, with some conservation practices, runs from $0 (solar heater) to over $300 per month.
